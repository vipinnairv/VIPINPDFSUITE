Digital signature (DSC)

A real certificate signature: the file is sealed so a reader can show who signed it and whether anything changed afterwards. Sign with the DSC on a USB token, or with a certificate file. Either way the document stays on this device - nothing about it is uploaded anywhere.

Plug your token in and press Look again.
Set up the token helper

Plug the token in, then press Look again. A browser cannot talk to a USB token by itself, so a small helper runs on this computer and does it. The document stays here: only a 32-byte hash of it is sent to the helper, and the PIN is typed on the helper's own window, never in this page.

Or drag a box on the page itself to put the signature exactly where you want it.
